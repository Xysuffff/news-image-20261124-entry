# World News Summary — 24 November 2026

This is an entry for the make.fun competition **["Sum up 24 November's world news in one image"](https://make.fun/bounty/news-image-20261124)**.

## The Image

The program writes a summary image of the world's news on Tuesday, 24 November 2026 to `/output/entry.png`.

## How it Works

- `main.ts` (Node 22, standard library only) copies `entry.png` to the output directory
- The image is a hand-crafted summary of major world events on 24 November 2026
- No network access; deterministic output
